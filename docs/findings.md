## Quantization Advisor Results

**Date:** 5 April 2026
**Fixtures:** HEPRS 100/500/1000/5000 SNP beta files

### Advisor recommendations (across all fixture sizes)

| Tier | Scale | Error vs plaintext | Notes |
|---|---|---|---|
| baseline | ~10² | ~1–15% MAE | Too lossy for clinical use |
| balanced | ~10⁶ | Machine epsilon | Recommended default |
| max_precision | ~10⁸–10¹⁰ | Machine epsilon | No improvement over balanced on current fixtures |

All 11 evaluated scale candidates pass overflow check (0 rejected) — uint64 is not the bottleneck.

Advisor runtime: ~0.2–0.26 s across all fixture sizes (effectively flat; safe to run routinely before every model publication).

**Conclusion:** Use `balanced`. The bottleneck is SNP upload transaction count, not scale precision.
