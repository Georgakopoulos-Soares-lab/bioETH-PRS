# Scaling Ceilings Reference

## Purpose

This document records a simple, reproducible overflow screen for PRS accumulation in the current unsigned integer setting.

It is intentionally a **quick reference**, not the final production bound. The production path should still rely on the quantization advisor and exact model-specific bounds.

---

## Assumptions behind this table

This reference uses the simplified conservative rule:

```text
scaling_factor × max_genotype_dosage × N_SNPs <= uint64_max
```

with:

* `max_genotype_dosage = 2`
* `uint64_max = 2^64 - 1 ≈ 1.84 × 10^19`
* `max_quantized_weight_per_snp ≈ scaling_factor`

That last assumption is equivalent to a quick-screen world where the per-SNP quantized weight magnitude is bounded by the chosen scale.

This is useful for:

* fast planning
* rough sanity checks
* docs and discussion

It is **not** the final proof for a real model, because real safety should also account for:

* the actual weight vector
* the true maximum absolute beta value
* zero-point corrections
* score offsets
* any future noise or extra arithmetic

For that, use the quantization advisor and exact model-specific bounds.

---

## Formula

For this simplified screen:

```text
max_accumulation = scale × 2 × N
```

So the safe SNP ceiling is:

```text
safe_N_ceiling = floor((2^64 - 1) / (2 × scale))
```

## Worked examples

### Scaling factor `10^8`

For `N = 5000`:

```text
max_accumulation = 5000 × 2 × 10^8 = 10^12
```

That is safely below `uint64_max`.

The simplified safe SNP ceiling is:

```text
floor((2^64 - 1) / (2 × 10^8)) = 92,233,720,368
```

### Scaling factor `10^12`

For `N = 5000`:

```text
max_accumulation = 5000 × 2 × 10^12 = 10^16
```

That is also still below `uint64_max` under this simplified screen.

The simplified safe SNP ceiling is:

```text
floor((2^64 - 1) / (2 × 10^12)) = 9,223,372
```
