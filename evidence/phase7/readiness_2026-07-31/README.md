# Local 100-SNP calculation data

## What was evaluated

This directory contains transaction data for public-weight and private-weight 100-SNP
calculations using the **Classic method (stored inputs)** in local simulation. No public network
was contacted.

## Results

The local measurements in this directory do not support conclusions about live FHE speed,
Sepolia behavior, or production cost.

## What the results mean

The public-weight and private-weight score results are reported in the [local 100-SNP calculation
summary](../readiness_2026-07-31_final/README.md).
