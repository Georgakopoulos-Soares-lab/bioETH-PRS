## Reproducibility caveats recorded at baseline

1. **Node version mismatch.** `.nvmrc` pins node 22; this capture ran on node v25.5.0.
   Hardhat 2.22 emits `WARNING: You are currently using Node.js v25.5.0, which is not
   supported by Hardhat.` Compile and all 137 tests pass regardless, but every artifact in
   this directory was produced on an unsupported runtime. Re-capture on node 22 before any
   number here is quoted in the manuscript, or state the runtime alongside it.
2. **`node_modules` was absent** before this capture, so the dependency tree was resolved
   fresh from `package-lock.json`. The lock file was not modified.
3. **Zero manifest hashes.** The baseline evaluation path writes `ethers.ZeroHash` for
   experimental manifests. This is the gap action `R2.4-E1` closes; see
   `../claim_deltas.md` entry CD-001 for the corrected file scope.
4. `deployments/chain-31337-validation-100snp.json` was regenerated by `validate:mock` with
   byte-identical content, so no tracked file changed during baseline capture.
